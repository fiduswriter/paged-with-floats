paged-with-floats demos

Live demonstrations of paged-with-floats, an LGPL fork of Paged.js with CSS page floats, footnotes, multi-column pagination, running headers and page numbers.

Floating figures in a two-column book — editable playground

  • The Malay Archipelago — two-column flow with page floats (float-reference: page; float: top) spanning both columns, footnotes collected at the bottom of the page, running chapter headers and page numbers. Edit the HTML source in the textarea, then hit “Render pages” to re-paginate, or “Download PDF” to export the current source as a real vector PDF.

Whole books in two to four columns

Full Project Gutenberg texts (public domain) paginated entirely in the browser. Running headers show the current chapter via string-set; footers carry page numbers. Each page offers a one-click Download PDF export.

  • Alice’s Adventures in Wonderland — Lewis Carroll, two columns.
  • Frankenstein — Mary Wollstonecraft Shelley, three columns.
  • Moby-Dick — Herman Melville, four columns.
